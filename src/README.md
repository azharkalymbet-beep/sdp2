# Assignment 2: Creational Patterns (Factory Method & Abstract Factory)

## Theme Chosen
**Coffee Kiosk**
- **Part A (Factory Method):** Brewing a single drink (Espresso, Latte, Cappuccino).
- **Part B (Abstract Factory):** Consistent serving-set family (Cup + Lid + Receipt) for different brand styles (Eco Style vs. Cyberpunk Style).

## Structure
- `src/factorymethod/` contains the implementation of Part A.
- `src/abstractfactory/` contains the implementation of Part B.
